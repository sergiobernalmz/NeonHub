# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in NeonHub, please report it by:
1. Email: [your-email@domain.com]
2. Do NOT open a public GitHub issue
3. Include as much detail as possible: steps to reproduce, affected versions, potential impact

## Response Timeline
- Acknowledgment: 24-48 hours
- Initial assessment: 3-5 business days
- Fix timeline: varies by severity (critical: 7 days, high: 30 days, medium: 90 days)

## Scope
This policy applies to:
- NeonHub SaaS platform (neonhub.es)
- API endpoints (/api/*, /api/v1/*)
- All subdomains (*.neonhub.es)

## Out of Scope
- Social engineering attacks
- Physical security
- DDoS attacks (use standard mitigation)
